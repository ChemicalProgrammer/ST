Model assumptions & timing

At 1×, one virtual second takes one real second. The engine integrates at 0.25 s; the display interval only controls replay detail and result size. Every conveyor uses FlowPilot physical geometry by default: L_act, L_p, package pitch, speed factor, runout, sensor delays, and insurance derive capacity, travel, normal photoeye pulses, Prime / Back-up control, recovery, and design audits. Abstract buffers are not used.
